# 🎨 BossHouse - Frontend UI Application

> **Giao diện người dùng Web Application** hiện đại, mượt mà dành cho hệ thống BossHouse Pet Hotel & Spa.

---

## 📌 Vai Trò Trong Dự Án
Thư mục `BossHouse_Frontend` cung cấp trải nghiệm tương tác trực quan cho Khách hàng (đặt phòng, đặt lịch chăm sóc, quản lý thú cưng) và Dashboard chuyên nghiệp cho Quản trị viên điều hành kinh doanh.

---

## 🛠️ Công Nghệ & Thư Viện Sử Dụng

- **React 18**: Thư viện UI phổ biến, tối ưu khả năng tái sử dụng component.
- **Vite**: Toolchain build dự án tốc độ cao, HMR tức thì.
- **Lucide React**: Bộ icon hiện đại, sắc nét.
- **CSS Custom / Responsive Design**: Giao diện linh hoạt, hiển thị tốt trên cả máy tính và điện thoại.

---

## 🚀 Khởi Chạy Nhanh

```bash
# 1. Di chuyển vào thư mục
cd BossHouse_Frontend

# 2. Cài đặt thư viện
npm install

# 3. Chạy giao diện phát triển
npm run dev
```

Ứng dụng sẽ khả dụng tại: `http://localhost:5173`

---

## 🖥️ Các Trang Giao Diện Chính

- **Trang chủ (`HomePage.jsx`)**: Giới thiệu trung tâm, dịch vụ nổi bật & đánh giá từ khách hàng.
- **Đặt phòng (`RoomsPage.jsx`)**: Hiển thị danh sách phòng, tiện ích & đặt phòng.
- **Dịch vụ (`ServicesPage.jsx`)**: Đặt lịch các gói Spa, Grooming, Khám sức khỏe.
- **Thú cưng của tôi (`MyPetsPage.jsx`)**: Quản lý hồ sơ các "Boss" của khách hàng.
- **Lịch sử đặt (`MyBookingsPage.jsx`)**: Theo dõi trạng thái đơn đặt lịch.
- **Trang quản trị (`AdminDashboard.jsx`)**: Quản lý tổng thể dành cho Admin/Staff.
